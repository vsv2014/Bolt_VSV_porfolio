# Security policy

This is a static, public frontend portfolio. It deliberately contains **no server-side API keys**, production credentials, or customer data. The "Ask AI" console is a local simulated retrieval experience, not a production LLM service.

## Reporting security concerns

If you discover a security vulnerability, **please don't publish exploit steps, secrets or personal data in a public issue**. Contact the maintainer using the email address linked in [the live portfolio](https://vsv2014.github.io/Bolt_VSV_porfolio/#contact), with a concise description and non-sensitive reproduction. If GitHub private vulnerability reporting is enabled, it is also an appropriate channel.

Ordinary UI, rendering, browser and accessibility defects belong in the public issue templates.

Only the latest code on the default branch is actively maintained. Security patches are handled as needed; no guaranteed response timeline is offered.
